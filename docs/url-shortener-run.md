# Run the URL Shortener

This guide runs the URL shortener service and creates a short link for the example URL:

```text
https://www.drikpanchang.com/festivals/ganesh-chaturthi/ganesh-chaturthi-date-time.html?geoname-id=4684888
```

## 1. Build the service

From the repository root, use JDK 21 and Maven:

```bash
mvn package -DskipTests
```

## 2. Start the service

```bash
java -jar target/agentic-sdlc-orchestrator.jar
```

The service listens on `http://localhost:8080`.

Keep this terminal running and use a second terminal for the API requests.

## 3. Create a short link

```bash
curl -i -X POST http://localhost:8080/api/v1/links \
  -H "Content-Type: application/json" \
  -d '{"url":"https://www.drikpanchang.com/festivals/ganesh-chaturthi/ganesh-chaturthi-date-time.html?geoname-id=4684888"}'
```

A successful response returns JSON similar to:

```json
{
  "code": "aB3xYz1",
  "targetUrl": "https://www.drikpanchang.com/festivals/ganesh-chaturthi/ganesh-chaturthi-date-time.html?geoname-id=4684888",
  "status": "active"
}
```

Copy the returned `code`. The exact code is generated by the service and will vary.

## 4. Check the shortened URL

Open this URL in a browser, replacing `<code>` with the returned code:

```text
http://localhost:8080/<code>
```

Or inspect the redirect without following it:

```bash
curl -i http://localhost:8080/<code>
```

The response should contain:

```text
HTTP/1.1 302
Location: https://www.drikpanchang.com/festivals/ganesh-chaturthi/ganesh-chaturthi-date-time.html?geoname-id=4684888
```

## 5. Check link metadata

```bash
curl -i http://localhost:8080/api/v1/links/<code>
```

## 6. Check service health

```bash
curl -i http://localhost:8080/health
```

## Stop the service

Press `Ctrl+C` in the terminal running the application.
